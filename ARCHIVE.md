# AISlidev Archive Notice

AISlidev is now in archived / sunset status.

## Why this project is being archived

The original goal of AISlidev was to provide an AI-assisted Slidev editing and presentation workflow. At this point, the core value proposition is sufficiently covered by newer general-purpose AI design tools such as Claude Design, and the maintenance cost of continuing this standalone project is no longer justified.

## Status

- Development: stopped
- Maintenance: stopped except for historical preservation
- Issue triage: closed / no longer accepting new feature work
- Repository intent: read-only historical reference

## What remains useful

- Prior experiments around Slidev-based presentation workflows
- Theme and PPTX export exploration
- Architecture and implementation notes for future reference

## What to expect

- No new features
- No bug fixes
- No dependency upgrades
- No support commitment

## Suggested replacement direction

For new work, prefer modern AI-native presentation and design workflows instead of extending AISlidev as a dedicated product.

## Local archival notes

This repository may be packaged into a local archive bundle together with a short markdown note and compressed snapshot for record-keeping.
