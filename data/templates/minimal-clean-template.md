# Minimal

A clean, distraction-free presentation

---

# Introduction

This template emphasizes **content over decoration**.

No fancy animations. No gradients. Just clear communication.

---

# Why Minimal?

<v-clicks>

- **Focus** - Nothing to distract from your message
- **Readability** - Large, clean typography
- **Professional** - Timeless, classic design
- **Versatile** - Works for any topic

</v-clicks>

---

# Key Points

1. Start with the most important information
2. Use whitespace effectively
3. Keep text concise
4. Let your content shine

---

# Example: Code

```typescript
// Clean, readable code
function getMessage(name: string): string {

}

const greeting = getMessage('World')
```

Simple. Clear. Effective.
